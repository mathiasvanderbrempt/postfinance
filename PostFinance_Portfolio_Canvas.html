Native Interaction Patterns
👆

Bottom Sheets

Half-height and full-height detents for filters, confirmations, and quick actions. Spring animation with 0.85 damping. 20px top corner radius with 36×5px grab handle.

👈

Swipe Actions

Leading swipe on transactions for quick pay/repeat. Trailing swipe on notifications to archive. Destructive actions require confirmation with haptic warning.

📱

Haptic Feedback

Success haptic on payment confirmation. Warning haptic on card freeze. Selection haptic on amount picker taps. Impact haptic on pull-to-refresh trigger.

🔍

Long Press Menus

Context menus on account cards (copy IBAN, share, rename). Transaction long press for quick categorize, add note, report. Uses SF Symbols for menu icons.

✨

Micro-animations

Balance count-up on load (600ms ease-out). Card flip for PIN reveal. Confetti on payment success. Progress ring fill on savings goals. Skeleton shimmer during loading.

🏝️

Dynamic Island

Payment progress indicator during transfer. Live activity for pending transactions. Compact view shows transfer amount, expanded shows full status with recipient.

Design → Dev Handover
Engineering Specs

Implementation Notes

  • SwiftUI preferred — UIKit for complex list animations and custom transitions only
  • NavigationStack with typed paths for deep linking support
  • @Observable macro for state management (iOS 17+)
  • Async/await for all network calls via structured concurrency
  • Keychain for biometric token storage via LocalAuthentication
  • Core Data + CloudKit for offline transaction cache
  • AVFoundation for QR code scanning with VNDetectBarcodesRequest
iOS 16+ Swift 5.9 Xcode 15 SwiftUI Accessibility
Accessibility

WCAG 2.1 AA

  • All contrast ratios ≥ 4.5:1 verified
  • Touch targets minimum 44×44pt
  • VoiceOver labels on every interactive element
  • Dynamic Type support (up to xxxLarge)
  • Reduce Motion: disable sparklines, count-up, confetti
  • Color-blind safe: never rely on color alone for status
Localization

4-Language Support

All strings externalized to .strings files. RTL not required. Number formatting uses Swiss locale (apostrophe thousands separator).
